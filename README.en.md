# Silent Love Sword

A Minecraft Forge mod that adds a mysterious "Silent Love Sword" to the game.

## Introduction

Silent Love Sword is a uniquely functional mod designed to introduce a special weapon to Minecraft, along with player protection mechanisms. The mod implements a series of advanced features through techniques such as custom entity rendering, event interception, and field tracking.

## Features

### Silent Love Sword
- A special sword usable in-game
- Unique attack animations and effects
- Custom item name display
- Can be placed in the Creative mode inventory tab

### Player Protection System
- Protects specific players from damage or death
- Supports managing the list of protected players via configuration file
- Prevents entities listed in the .bad list from attacking

### Entity Management
- Intelligent entity filtering system
- Automatic cleanup of malicious entities
- Supports custom .bad entity lists

### Advanced Features
- PreciseFieldBackTrackManager for accurate field tracking
- Dynamic class definition and loading
- Hidden class support
- Event bus interception

## Supported Versions

This mod is compatible with Minecraft Forge versions.

1. Download the Forge installer corresponding to your Minecraft version

## Configuration

### Player Protection List
The mod creates a configuration file in the `config` directory; you can manually add player names to be protected.

### Custom Entity List
Use EntityUtil to add custom entities to the .bad list.

This mod utilizes the following advanced technologies:
- **ASM/Javassist**: Bytecode manipulation
