

# 寂爱之剑 (Silent Love Sword)

一个 Minecraft Forge 模组，为游戏添加一把神秘的"寂爱之剑"。

## 简介

寂爱之剑是一款功能独特的 mod，旨在为 Minecraft 添加一种特殊武器，并提供玩家保护机制。该模组通过自定义实体渲染、事件拦截和字段追踪等技术，实现了一系列高级功能。

## 功能特性

### 寂爱之剑 (SilentLoveSword)
- 可在游戏中使用的特殊剑
- 独特的攻击动画和效果
- 自定义物品名称显示
- 可放入创意模式标签页

### 玩家保护系统
- 保护特定玩家不被伤害/击杀
- 支持通过配置文件管理受保护玩家列表
- 防止被加入.bad列表的实体攻击

### 实体管理
- 智能实体过滤系统
- 自动清理恶意实体
- 支持自定义.bad实体列表

### 高级功能
- 精确字段回溯管理 (PreciseFieldBackTrackManager)
- 动态类定义与加载
- 隐藏类支持
- 事件总线拦截

## 支持的版本

该模组适用于 Minecraft Forge 版本。

## 安装方法

1. 下载与你的 Minecraft 版本对应的 Forge 安装程序
2. 运行 Forge 安装程序创建客户端/服务器端
3. 将本模组放入 `mods` 文件夹
4. 启动游戏或服务器

## 配置说明

### 玩家保护列表
模组会在 `config` 目录创建配置文件，可手动添加需要保护的玩家名称。

### 自定义实体列表
可通过 EntityUtil 添加自定义的实体到.bad列表。

## 技术细节

该模组使用了以下高级技术：
- **ASM/Javassist**: 字节码修改
- **MethodHandle**: 动态方法调用
- **FieldBackTrack**: 字段值捕获与回溯
- **Hidden Class**: 运行时动态定义类
